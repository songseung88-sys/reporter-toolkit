1. 서비스 목적

TC Finder는 사용자가 열린 클로바노트 페이지에서 녹취록을 확인하고, 사용자가 입력한 편집 문장에 시작 타임코드(TC)를 삽입하도록 돕는 독립적인 크롬 확장 프로그램입니다.

2. 처리하는 정보

사용자가 TC 찾기 기능을 실행할 때, 현재 열린 클로바노트 상세 페이지에 표시되는 녹취 텍스트, 발화 시간 및 재생 시각과 확장 프로그램에 사용자가 입력한 편집 문장을 브라우저 안에서 처리합니다. 결과는 확장 프로그램 사이드 패널에 표시됩니다.

3. 저장 및 외부 제공

해당 기능은 로컬 브라우저 메모리에서 동작하며, 개발자가 운영하는 서버로 녹취록·편집문을 전송하지 않습니다. 확장 프로그램이 분석 데이터를 원격 서버에 저장하거나 제3자에게 판매·공유하지 않습니다. 사용자가 '복사' 버튼을 클릭하면 결과가 시스템 클립보드에 저장됩니다.

4. 접근 권한

TC Finder는 clovanote.naver.com 웹페이지의 녹취 내용 및 재생 컨트롤을 읽거나 제어하기 위한 사이트 접근 권한과, 오른쪽 사이드 패널 표시를 위한 권한을 사용합니다. 다른 웹사이트의 콘텐츠는 접근 대상이 아닙니다.

5. 보관 및 삭제

확장 프로그램은 녹취록과 편집문을 영구 저장하지 않습니다. 탭을 닫거나 페이지를 새로고침하면 페이지 분석 데이터가 사라지고, 사이드 패널을 닫으면 패널 입력 데이터는 보관되지 않습니다. 확장 프로그램을 삭제하면 확장 프로그램 자체가 제거됩니다.
